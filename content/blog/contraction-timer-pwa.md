After seeing my friend Michael Dennis's recent presentation on Progressive Web Apps, I've decided to dip my toes in while creating something useful: a pregnancy contraction timer! Super simple, client-side only application that I hammered out with Claude Code.

[Try it out](https://contraction-timer.calebdudley.dev)

It's hosted on Azure as a static web app, complete with a build pipeline and test environment. It's even got dark mode!

[Source code](https://github.com/ca1ebd/contraction-timer)

It allows you to edit contractions, which the app I had used previously decided was a paid feature&hellip; hence the rebuild.
